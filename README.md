# ClipNova

**AI-powered video and livestream clipping workspace.**

ClipNova is being developed as a unified creator tool inspired by the strongest workflows found across OpusClip, StreamLadder, Eklipse, Vizard, and Spikes Studio. It will combine long-video repurposing, live-stream clipping, gaming highlights, a hands-on editor, and social-ready exports in one product.

## Product direction

- Import local videos and supported YouTube, Twitch, and Kick sources.
- Detect engaging moments in recordings and, where technically supported, active livestreams.
- Generate multiple short clips with configurable duration and aspect ratio.
- Reframe landscape footage for vertical, square, and widescreen outputs.
- Create editable captions, titles, hooks, and descriptions.
- Provide a manual editor for trimming, crop/zoom, caption styling, and clip review.
- Organize media, jobs, and exports in a creator workspace.
- Export platform-ready files and prepare social publishing integrations.

## Development principles

1. **One coherent product:** no disconnected competitor feature clones.
2. **Real capabilities:** label integrations and AI features accurately; never present mock actions as working.
3. **User control:** generated clips remain editable before export or publishing.
4. **Privacy and security:** keep API keys and user media out of source control; isolate workspace data.
5. **Legal respect:** retain applicable upstream license and copyright notices when reusing code; create original ClipNova branding and interface assets.
